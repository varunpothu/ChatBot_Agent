# AI Assurance Framework

CoachAI treats assurance as evidence that the system is operating within defined controls.

## Assurance dimensions

1. Grounding: claims must be supported by retrieved evidence.
2. Retrieval: benchmark questions must meet agreed retrieval thresholds.
3. Safety: prompt injection and unsafe input tests must pass.
4. Governance: every model/prompt release has an owner and version.
5. Transparency: user-visible answers expose source references.
6. Human oversight: uncertain cases have an escalation path.
7. Operations: latency, errors and abstentions are monitored.
8. Change control: production promotion requires an evaluation report.

## Release principle

No passing evaluation report, no production promotion.
